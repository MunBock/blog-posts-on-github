# Outline: How to Write a Blog Post Prompt

## I. Define the Role & Persona

- **Assign Identity**: (e.g., "Act as a Senior React Developer," "You are a Fitness Coach.")
- **Establish Credibility**: Mention years of experience or specific expertise.
- **Set the Voice**: (e.g., "Authoritative yet accessible," "Witty and conversational.")

## II. Set the Context & Background (The "Why")

- **Topic Background**: Briefly describe the current state of the topic.
- **The Problem/Conflict**: identifying the specific pain point the reader is facing (e.g., "Junior devs feel isolated in remote work").
- **The Goal**: What should the reader walk away with? (e.g., "3 actionable strategies," "A clear understanding of hydration.")

## III. Specify the Audience (The "Who")

- **Target Demographics**: Beginners vs. Experts, C-level execs vs. Hobbyists.
- **Prior Knowledge**: What do they already know vs. what needs explaining?
- **Reader Intent**: Are they looking to buy, learn, or be entertained?

## IV. Define the Task (The "What")

- **Content Type**: Blog post, completely comprehensive guide, listicle, case study.
- **Title Options**: Ask for 5-10 click-worthy titles first (optional but recommended).
- **Key Sections to Cover**:
  - Introduction (Hook)
  - Core Concepts (The "Meat")
  - Actionable Tips (The "How-to")
  - Conclusion & Call to Action (CTA)

## V. Set Constraints & Formatting (The "Rules")

- **Length**: Word count range (e.g., "800-1200 words").
- **Formatting**: Markdown, H2/H3 headers, bullet points, bold text for emphasis.
- **Restrictions**: "No fluff," "Avoid jargon," "Do not use the word 'unleash'."
- **SEO Requirements**: Keywords to include, meta description length.

## VI. Review & Refine (The "Loop")

- **Iterative Approach**: Ask for an outline first > Approve/Edit > Generate full post.
- **"Show, Don't Tell"**: Ask for examples, metaphors, or analogies to explain complex ideas.
- **Tone Check**: "If it sounds too robotic, rewrite the introduction to be more personal."

## VII. Example Prompt Structure (Template)

- **Role**: [Insert Persona]
- **Context**: [Insert Background & Problem]
- **Task**: Write a [Length] blog post about [Topic] for [Audience].
- **Outline**:
  1.  [Point 1]
  2.  [Point 2]
  3.  [Point 3]
- **Constraints**:
  - Use [Tone] voice.
  - Include [Number] examples.
  - Format in Markdown.
